# بازی‌خوان

وب‌سایت فارسی تحلیل مسابقات فوتبال. صفحه مسابقات را از API عمومی ESPN می‌گیرد، احتمال‌ها را با مدل Dixon–Coles محاسبه می‌کند و در صورت وجود ضرایب، برآورد مدل را با احتمال بدون حاشیهٔ بازار ترکیب می‌کند. نتایج تمام‌شدهٔ ESPN هم به تاریخچهٔ آموزشی اضافه می‌شوند.

## اجرای محلی

از ریشهٔ پروژه یک وب‌سرور محلی اجرا کنید تا فایل‌های داده و اسکریپت‌ها با مسیرهای نسبی بارگذاری شوند:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. برای دریافت مسابقات، مرورگر باید به اینترنت وصل باشد. ESPN یک API عمومی است و دسترس‌پذیری یا قالب آن تضمین‌شده نیست.

## تاریخچه و بک‌تست

`data/history.js` تاریخچهٔ فشردهٔ نتایج، xG و ضرایب را نگه می‌دارد. برای بازسازی آن از Football-Data و تطبیق شناسهٔ تیم‌ها با ESPN:

```bash
python tools/build_data.py
```

برای گزارش walk-forward موجود:

```bash
node tools/backtest.js
```

این پروژه نمونهٔ پژوهشی است؛ کیفیت پیش‌بینی به پوشش تاریخچه، کیفیت ضرایب، تطبیق صحیح تیم‌ها و ارزیابی خارج از نمونه وابسته است. نتایج بک‌تست تضمین عملکرد آینده نیستند.

## تحلیل Claude (اختیاری)

کاربر می‌تواند کلید API شخصی را از دکمهٔ تنظیمات وارد کند. کلید فقط در `localStorage` همان مرورگر نگه‌داری می‌شود و درخواست مستقیم از مرورگر به Anthropic فرستاده می‌شود. این روش برای انتشار عمومی مناسب نیست: کاربران باید کلید خودشان را وارد کنند. برای سرویس عمومی با کلید متعلق به برنامه، درخواست‌ها را از پراکسی سمت‌سرور عبور دهید و کلید را در متغیر محیطی نگه دارید.

تحلیل Claude خبرهای بیرونی را خلاصه می‌کند و ممکن است خطا کند؛ خروجی آن جایگزین مدل آماری یا منبع قطعی خبر نیست. استفاده از API ممکن است هزینه داشته باشد.

## انتشار

سایت فایل‌های استاتیک است و build لازم ندارد؛ می‌توان آن را روی GitHub Pages منتشر کرد. فایل `data/history.js` را هم در مخزن نگه دارید. اتصال زندهٔ مرورگر به ESPN و تنظیمات CORS آن باید در دامنهٔ انتشار بررسی شود. برای داده یا API دارای کلید، از پراکسی سمت‌سرور استفاده کنید و هیچ راز یا کلیدی را در فایل‌های عمومی قرار ندهید.

## مسئولانه

احتمال‌ها تخمین‌اند، نه توصیهٔ تضمینی یا وعدهٔ سود. شرط‌بندی ریسک مالی و اعتیاد دارد؛ فقط در چارچوب قوانین محل زندگی و در حد توان مالی خود عمل کنید.
